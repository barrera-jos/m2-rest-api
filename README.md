# MP2: Data Processing REST API

This project is a FastAPI application that wraps the MP1 data-cleaning pipeline in a REST API. `GET /health` returns the app's status and version. `POST /upload` accepts a CSV file, stores it in memory, and returns its metadata (ID, filename, row and column counts, and column names), rejecting files that aren't CSVs or can't be parsed. `GET /datasets/{dataset_id}` returns up to `limit` rows of a stored dataset along with its total row count, and `POST /datasets/{dataset_id}/process` takes a JSON configuration, validated by Pydantic request models, that controls which columns are required and numeric, whether duplicates are removed, how missing values are handled, and whether outliers are removed using the IQR or z-score method. Processing updates the stored dataset and returns a report of how many rows validation and cleaning removed, and requests for datasets that don't exist return a 404. A logging middleware records each request's ID, method, path, status code, and duration, and attaches the request ID to the response as an `X-Request-ID` header. The pytest suite covers uploading, processing and retrieving a dataset, and requesting a missing dataset.
